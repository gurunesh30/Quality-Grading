# `frontend` — owned by branch `frontend`

React + TypeScript + Vite web client. No file in this directory may be edited
from the `feature-extraction` or `model` branches.

## Scope

- Live camera capture via `getUserMedia`, with a still-capture fallback and an
  on-screen reference marker (ArUco tag or coin) for scale calibration.
- Upload / retake / calibration-guidance flow.
- Grade result view: grade, confidence, and the per-feature XAI breakdown
  returned by the API.
- Grade history for a session.

## Status

The UI is implemented against the documented API contract and runs on fixtures
until the routes in `src/agrigrade/api/routes/` land. The header shows a
**Mock API** badge whenever mock mode is on.

## Running

```bash
npm install
npm run dev            # http://localhost:5173, mock mode
```

To point at a real API:

```bash
cp .env.example .env.local
# VITE_API_BASE_URL=http://localhost:8000
```

`VITE_API_BASE_URL` unset (or set to `mock`) selects the fixture transport in
`src/api/mock.ts`; anything else selects `fetch`.

## Checks

```bash
npm run typecheck      # tsc -b --noEmit
npm run lint           # oxlint
npm test               # vitest run
npm run build          # tsc -b && vite build
```

`src/components/ui/` is generated by `shadcn`. Everything outside it is hand
written and expected to be lint-clean; the three `react(only-export-components)`
warnings from the generated files are upstream.

## Theming

The visual language is the **Graphite** theme from tweakcn
(`https://tweakcn.com/r/themes/graphite.json`), installed as CSS custom
properties in `src/index.css`. It is a neutral grayscale palette with a 0.35rem
radius and hard offset shadows.

- Add components with `npx shadcn@latest add <name>`; the `@/` alias points at
  `src/` (see `components.json` and the `paths` entry in `tsconfig.app.json`).
- Use the semantic tokens (`bg-card`, `text-muted-foreground`,
  `border-border`) rather than raw greys so dark mode keeps working.
- Dark is the default; `useTheme` persists a choice to `localStorage`, and an
  inline script in `index.html` applies it before first paint.

## Boundary rules

- The client knows nothing about OpenCV, Random Forest internals or pixel math.
  It consumes the JSON contract in `src/agrigrade/api/` and nothing else.
- Produce classes and grade strings are mirrored from
  `agrigrade.core.enums` in `src/types/grades.ts`. When a new value lands in
  that enum, update `src/types/grades.ts` in the same PR.
- Camera frames stay in the browser unless the user submits them. The on-device
  claim in the README means no frame is retained server-side by default.

## Contract mirror

`src/types/grades.ts` mirrors `agrigrade.core.enums`:

| Python | TypeScript |
| --- | --- |
| `ProduceFamily` | `ProduceFamily` + `PRODUCE_FAMILIES` |
| `ProduceClass` | `ProduceClass` + `PRODUCE_CLASSES` |
| `QualityGrade` | `QualityGrade` + `QUALITY_GRADES` |
| `GRADE_ORDER` | `QUALITY_GRADES` order, asserted in tests |
| `CLASS_TO_FAMILY` | `CLASS_TO_FAMILY` |
| `family_for` | `familyFor` |

A test asserts that the ladder order matches the classifier's training order.

## Tests

`vitest` + Testing Library, colocated as `*.test.ts(x)`. The API client is
exercised through stub transports and the fixtures; no browser or camera is
required to run the suite. Coverage focuses on contract correctness — enum
mirrors, envelope guards, calibration arithmetic — and on the accessibility
behaviour that is easy to regress (grade badges not relying on colour alone,
confidence exposed as a `progressbar`).
