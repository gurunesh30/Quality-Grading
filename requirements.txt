# AgriGrade AI — full-stack runtime and development requirements.
#
# The same dependency groups are declared in `pyproject.toml` as optional
# extras. This file is the flattened union of all of them, for environments that
# install from a single requirements file rather than the project metadata:
#
#     pip install -r requirements.txt
#     pip install -e .
#
# Install the extras instead if you only need one workstream:
#
#     pip install -e ".[features]"   # numpy, opencv, scikit-image
#     pip install -e ".[model]"      # numpy, scikit-learn, joblib
#     pip install -e ".[api]"        # fastapi, uvicorn, python-multipart, pillow
#
# NOTE: `shap` is deliberately absent. `agrigrade.model.xai` computes local
# attributions by single-feature occlusion, which needs only `predict_proba`, and
# the specification's edge deployment target has no room for TreeSHAP's
# compile-time dependency.
#
# It is still declared in the `model` extra in pyproject.toml, which is now
# inaccurate: nothing under src/ imports `shap`, `onnx` or `onnxruntime`. Those
# three extras are dead weight and can be dropped once the ONNX export path in
# the specification lands. This file omits shap and keeps onnx/onnxruntime only
# because the export target is still open.
